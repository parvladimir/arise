# AI RISE — прототип

Браузерная игра о карьере с ИИ: от первого запроса к нейросети до собственной студии.
Это локальный прототип основного цикла (квесты Q1–Q5): диалог, работа с «Нейрой» через карточки запроса, оплата, магазин, заказ с доски.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # движок, экономика, сохранения, симуляция
npm run lint       # проверка типов
npm run sim        # прогон экономики тремя профилями игроков
```

Сохранение хранится в `localStorage` браузера (`ai-rise.save`). Внешних ключей, сервера и облачных ресурсов прототипу не нужно.

## Устройство

- `src/core` — чистая логика без React: `engine.ts` (`apply(state, action)`), `promptSim.ts` (детерминированная «Нейра»), `economy.ts`, `save.ts` (версии и миграции).
- `src/content` — квесты, карточки, предметы и тексты (`locales/ru.ts`). Новый контент добавляется данными, без правок движка.
- `src/ui` — интерфейс: комната, ноутбук с приложениями, телефон, тосты.
- `tools/sim` — симуляция экономики.
